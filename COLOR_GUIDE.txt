LIRLD COLOR GUIDE
=================

BRAND COLORS
------------
Primary Navy   : #010b80  — this IS the brand color AND the sidebar background.
                            They are intentionally the same. The sidebar IS the brand.
White          : #ffffff  — primary contrast color against the navy brand


Because the brand color doubles as the sidebar bg, active nav items flip to
white (bg-white text-[#010b80]) to create contrast — not because they are
"different" surfaces, but because inversion is the only way to show selection
on a solid brand-colored background.


SIDEBAR (surface: #010b80 = brand primary)
-------------------------------------------
Background     : bg-[#010b80]
Text default   : text-white/80       (readable, not harsh full white)
Text hover     : text-white          (full white on hover)
Text active    : text-[#010b80]      (navy on white pill — high contrast)

Nav item inactive  : text-white/80  hover:bg-white/10  hover:text-white
Nav item active    : bg-white  text-[#010b80]  shadow-md
Nav item focus     : ring-2 ring-white/50 (for keyboard nav)

Icon color     : inherits from parent text color (no separate icon class needed)


LIGHT SURFACES (cards, main content area)
------------------------------------------
Background     : bg-white  /  dark: bg-zinc-900
Primary text   : text-gray-900  /  dark: text-white
Secondary text : text-gray-500  /  dark: text-zinc-400
Border         : border-gray-200/50  /  dark: border-zinc-800/50


INTERACTIVE ELEMENTS
---------------------
Primary button : bg-linear-to-r from-pink-500 to-violet-600  text-white
                 hover: shadow-pink-500/40  hover:-translate-y-0.5

Hover on dark  : hover:bg-white/10   (subtle, visible on navy)
Hover on light : hover:bg-gray-100   (subtle, visible on white)

Active/selected pill on dark bg  : bg-white text-[#010b80]
Active/selected pill on light bg : bg-[#010b80] text-white


UPGRADE / PRO CARD (on dark sidebar)
--------------------------------------
Card bg        : bg-linear-to-br from-pink-500/8 via-violet-500/8 to-blue-500/8
Border default : border-pink-500/10
Border hover   : hover:border-pink-500/30
Icon container : bg-white  border-pink-500/20
Icon color     : text-pink-500
Heading        : text-white
Body text      : text-white/70


CONTRAST RULES (WCAG AA minimum 4.5:1 for normal text)
--------------------------------------------------------
white on #010b80        : ~15:1  PASS
white/80 on #010b80     : ~12:1  PASS
#010b80 on white        : ~15:1  PASS
pink-500 on white       : ~3.4:1 — use only for large/bold text or icons
pink-500 on #010b80     : ~3.6:1 — use only for icons/decorative, not body text
white on pink-500 btn   : ~4.6:1 PASS


CONSISTENCY RULES
-----------------
1. Never mix react-icons and solid-icons — use solid-icons/io only.
2. All nav items must share the same activeClass and inactiveClass pattern.
3. Icons inherit text color from parent — do not set icon color separately
   unless it's a standalone decorative icon (e.g. diamond in promo card).
4. Hover states on dark surfaces always use white/10 overlay.
5. Hover states on light surfaces always use gray-100 overlay.
6. Active states always invert: dark bg → white pill, light bg → navy pill.
